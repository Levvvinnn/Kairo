# Contributing to Kairo

Thanks for your interest in contributing. Small improvements welcome — please follow these guidelines:

- Fork the repository and open a pull request with a clear title and description.
- Keep changes small and focused; one PR per logical change.
- Run existing tests where applicable and add tests for new features.
- Follow existing code style and use the provided `pyproject.toml`/`requirements.txt` for tooling.
- For security-sensitive issues (exposed tokens or secrets), contact the maintainers directly and do NOT open a public issue with secrets.

Maintainers will review and provide feedback.
